# Известные проблемы (issues)

Список открытых проблем инструмента. Доработать позже.

## PDF-парсер (GostFormParser / pdf-inspector)

### P1. Артефакты порядка слов на повёрнутых страницах
- **Симптом**: у строк повёрнутых страниц (Система водоснабжения/водоотведения)
  порядок слов внутри имени частично перепутан: «10-6 N=0,6 Насос Гном квт» вместо
  «Насос Гном 10-6 N=0,6 квт»; «Кран шаровой латунный Чикаго , Ду 15, PN 2,5 МПа»
  (запятая перед «Ду»).
- **Причина**: pdf-inspector разбивает многострочные/длинные ячейки на отдельные
  токены, координаты X которых не дают однозначного порядка чтения. Ротация
  страниц не решает (pdf-inspector игнорирует /Rotate).
- **Статус**: данные не теряются, имена поископригодны по ключевым токенам.

### P2. Строки без имени и количества в источнике
- **Симптом**: Система водоснабжения — 2 строки (№8, №9) без имени и количества
  (только номер + ГОСТ + ед.), помечены `requires_review`.
- **Причина**: в исходном PDF эти ячейки пустые. Парсер извлекает всё, что есть,
  и не фабрикует данные.
- **Статус**: корректное поведение, отмечено для ручной проверки.

### P3. Стыки групп наследования матерей
- **Симптом**: отдельные строки на границе групп наследуют соседнюю мать
  (например, «Трубы стальные водогазопроводные обыкновенные» попали к
  «Разбавитель клея Energopro» / «Трубка ENERGOFLEX» в некоторых прогонах).
- **Причина**: границы групп по Y на объединённых ячейках — эвристика.
- **Статус**: частично исправлено (позиция = наличие количества, значимые токены);
  остаточные случаи требуют доработки.

### P4. Количества на повёрнутых страницах
- **Симптом**: часть строк Системы водоснабжения qty=0.
- **Причина**: в исходном PDF количества физически отсутствуют в текстовом слое
  (проверено дампом координат: только единицы «м»/«шт» без цифр) — дефект источника.
