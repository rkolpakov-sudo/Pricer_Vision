## 1. Контекст и принцип

Разбор `log.md` (прогон 17:27–19:51, 24 строки, 10/23 найдено, 13 max-rounds,
остановлен пользователем) выявил чёткую череда фейлов на строках с «полностью
аналогичным наименованием» (LEMAX C10/C20, отличается только размер) и
неадекватный рост времени (308–786 с на ненайденную строку).

**Принцип реализации** (согласован с пользователем):
- **Скрипты — невидимая, безотказная сантехника для LLM, а не замена его решений.**
- НЕ выжимаем LLM из проекта: не пишем детерминированные генераторы запросов,
  детерминированные «код-гарды залипаний» и скриптованный «ранний выход».
- Скрипты: (а) убираем деструктивные (амнезия trim, слепая деприкация, блэклист,
  выбивающий сайт с товаром); (б) чиним обвязку, ломающую действия LLM (strict-mode,
  css-parse role-локаторов, мёртвые ref, слепые таймауты); (в) даём LLM информацию
  (факты, ключевые токены, рабочие паттерны), а не инструкции.

## 4. Фаза 1 — убрать деструктивные скрипты (память и обучение LLM)

### 1.1 Неубиваемая память фактов внутри строки (лечит П3)
**Файлы:** новый `src/session_facts.py` (`RowFacts`), `src/agent_loop.py` (`_query_llm`, `process_row`).
- `RowFacts` — операционная память строки, накапливается детерминированно (без LLM):
  посещённые домены+статус, реально введённые запросы, счётчик одинаковых извлечений
  (key + hash результата), `price_candidate_seen`, открытая карточка, последние ошибки.
- В `_query_llm` добавлен опциональный `facts=None`; перед каждым вызовом LLM после trim
  вставляется свежее user-сообщение «ФАКТЫ СЕССИИ…» (генерируется заново → переживает обрезку).
- Точки записи в `process_row`: navigate/snapshot → site visit + card open; browser_type → query;
  browser_evaluate → повтор извлечения; `_is_empty_search_result` → empty; price-candidate;
  `error:` → record_error.
- **НЕ скриптовый «код-гард»**: факт о повторе формулируется как факт («извлечение повторено
  N раз подряд с одинаковым результатом»), решение — за LLM.
- Тесты: `test_session_facts.py` (накопление, repeat_streak, блок промпта, price_candidate).
- [x] РЕАЛИЗОВАНО: `src/session_facts.py` (RowFacts + `REPEAT_NOTICE_THRESHOLD`),
  `_inject_facts_block` в `agent_loop.py`, 5 точек записи в `process_row`, `facts=facts`
  во все вызовы `_query_llm`. Тесты 13 шт.
